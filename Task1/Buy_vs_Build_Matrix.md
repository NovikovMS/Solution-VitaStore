# Матрица решений (Sourcing Strategy / Buy vs Build)

На основе аудита и выделенных возможностей сформирована стратегия сорсинга.

| Бизнес-возможность | Текущее состояние | Целевая модель (Стратегия) | Обоснование |
| :--- | :--- | :--- | :--- |
| **Пробитие чеков (POS/Касса)** 🔴 | Разнородный десктопный софт, локальные БД, толстый клиент | **SaaS (Buy)** / Cloud POS | Пробитие чеков — стандартизированный процесс (Commodity), не дающий уникального преимущества. Готовое облачное решение позволит отказаться от локальных серверов и снизить TCO. |
| **Программа лояльности** 🔴 | Разрозненная ("в тетрадке") или локальная | **SaaS (Buy)** | Стандартная функция для ритейла, выгоднее использовать готовое облачное решение с API для интеграции с кассами. |
| **Управление промоакциями (Promo Engine)** 🟢 | Единый движок промоакций | **In-house / On-Premise** | Является Differentiator-ом сети, тесно связано со спецификой бизнеса и кросс-продажами. Оставляем внутреннюю разработку и поддержку. |
| **Омниканальная логистика (Smart Fulfillment)** 🟢 | Собственная система | **In-house / On-Premise** | Уникальное конкурентное преимущество (Click & Collect), сложная интеграция со складами и магазинами. Оставляем In-house. |
| **Интеграция номенклатуры (SKU Mapping)** 🔴 | Ручной труд товароведов (Excel, VLOOKUP) | **PaaS (Build in Cloud)** | Уникальная внутренняя боль при M&A. Требуется кастомный сервис на базе облачных AI/ML решений (управляемых сервисов) для интеллектуального маппинга товаров. |
| **Инфраструктура магазинов (БД, Серверы)** 🔴 | MS SQL/PostgreSQL на локальных ПК в подсобке | **PaaS/IaaS (Migrate to Cloud)** | Поддержка забирает 40% ИТ-бюджета. Переход на управляемые облачные базы данных (Managed DB) для центрального хранения и тонких клиентов. |
| **Расчет премий, прием товара, печать ценников** 🔴 | Децентрализовано на локальном уровне | **In-house (Migrate to SAP ERP)** | Эти функции не требуют новых решений, их следует централизовать и перевести в уже имеющуюся мощную on-premise систему SAP ERP в HQ, отказавшись от локальных костылей. |
| **Интеграция с платежными терминалами** 🔴 | Прямая (жесткая) интеграция с кассой, отсутствие драйверов | **PaaS (Build in Cloud)** | Разработка единого слоя абстракции (Payment Gateway / HAL) In-house, возможно на базе облачной инфраструктуры, чтобы унифицировать работу с любыми терминалами. |
